# Register Form
A simple registration form built with HTML, CSS, and JavaScript.

## Fields
- Username
- Password
- Place of birth (Phnom Penh, Kampot, or Kandal)

## How to use
Open `RegisterForm.html` in a web browser, fill in the form, and select **Submit**. The entered values are printed in the browser's developer console, and the form fields are cleared.

To view the output, open the browser developer tools and select the **Console** tab.

## Files
- `RegisterForm.html` — form structure
- `RegisterForm.css` — page styling
- `RegisterForm.js` — submit handling and console output
